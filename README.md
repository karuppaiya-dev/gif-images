# Prank QR Code Page

A simple prank project that generates a QR code linking to a prank GIF webpage.

### QR Code
![QR Code](./qrcode.png)

---

## Features

- Displays prank GIF webpage  
- Generates shareable QR code  
- Scan QR → opens prank page instantly

---

## Tech Used

- HTML  
- Node.js  
- qrcode package

---

## Installation

```bash
git clone https://github.com/your-username/prank-qr-page.git

cd prank-qr-page

npm install
```

---

## Generate QR Code

```bash
node index.js
```

Creates:

```bash
qrcode.png
```
